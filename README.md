# Site Tandem

Site vitrine indépendant, en français, sans compilation ni dépendance JavaScript. Les fichiers servis sont dans `dist/`.

Prévisualisation : `node serve.mjs`, puis ouvrir http://127.0.0.1:4178.

Le téléchargement pointe vers les publications officielles GitHub afin de laisser choisir un installateur réellement disponible. La coopération est indiquée comme en développement. L’interface miniature est un aperçu illustratif, pas une capture du produit.

Le paysage original est dessiné en Canvas et le bouton « Changer d’horizon » génère une nouvelle composition. La police Geist est embarquée ; voir sa licence dans `dist/assets/`.
